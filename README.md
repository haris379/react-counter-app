A simple React Counter application built while learning React from **Mosh Hamedani's React Tutorial**. This project demonstrates the core concepts of React by implementing a shopping cart–style counter system where users can increment, reset, and manage multiple counters.

# What's in it?

This repository contains the source code developed during my React learning journey with **Mosh Hamedani's React Course**. The project focuses on understanding React fundamentals by building a reusable and interactive counter application.

The application includes features similar to a shopping cart, where users can increase item counts, reset all counters, and dynamically update the user interface based on the application state.


## ✨ Available Features

* Responsive Navigation Bar
* Display Active Counter Badge
* Multiple Counter Components
* Increment Counter Value
* Reset All Counters
* Delete Individual Counter
* Dynamic Badge Colors
* Responsive Bootstrap UI

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/react-counter.git
```

Navigate into the project:

```bash
cd react-counter
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser:

```
http://localhost:5173
```
